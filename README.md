# One-Line Laugh Sprint

Entry for the make.fun competition **One-Line Laugh Sprint**
(`u-daring-gecko-25-one-line-laugh-sprint-cda708b2`).

`main.ts` is a small Node program that writes exactly one original
funny line about everyday life to `/output/entry.txt`:

> My smart fridge ordered 40 litres of milk at 3 a.m. and now I respect it — it's the only one in this house with a five-year plan.

Run it with Node 22 or later:

```sh
node main.ts
```

Standard library only; nothing to install.
